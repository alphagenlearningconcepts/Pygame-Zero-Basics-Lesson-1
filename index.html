Game Characters

What is an Actor?

An Actor combines a graphic image with position coordinates (x, y)!

X Position: 200
Y Position: 125
Full Pygame Zero Code Syntax Stage Sync
Generated Syntax:
WIDTH = 400
HEIGHT = 300
hero = Actor("alien")
hero.pos = (200, 125)
def draw():
screen.fill("skyblue")
hero.draw()

Important: All image files MUST be stored inside the 'images/' subfolder!
