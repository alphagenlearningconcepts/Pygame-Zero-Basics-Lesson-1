MEET THE HERO

What is an Actor in Pygame Zero?

An Actor is a game character or object that combines an image with position properties like coordinates and rotation!

📁 Folder Rule:

All image files MUST be saved inside an images/ subfolder in your project directory!

.x

Horizontal position

.y

Vertical position

.pos

Tuple coordinate (400, 300)

.angle

Rotation angle in degrees
